# ملفات Madabina CLI التنفيذية

Madabina CLI برنامج احتكاري توزعه Madabina LLC. هذا المستودع مخصص لتوزيع الإصدارات الرسمية بصيغة ملفات تنفيذية، ولا يحتوي على الشيفرة المصدرية للبرنامج.

## حالة الإصدارات

لا يتوفر حالياً أي إصدار عام مرقّم. ستُنشر التنزيلات الرسمية في [صفحة إصدارات Madabina CLI](https://github.com/madabina-com/madabina-cli/releases). لا تثبّت ولا تعِد توزيع الملفات التي تحمل العلامة `SNAPSHOT`؛ فهي ملفات محلية للاختبار وليست إصدارات رسمية.

عند نشر إصدار رسمي، ستُرفق به الملفات المضغوطة وحزم Debian وملف التحقق SHA-256. اختر الملف الموافق لنظام التشغيل ومعمارية المعالج، ثم تحقّق من قيمة SHA-256 قبل التثبيت. تؤكد قيمة التحقق التي تُنزّل من الإصدار نفسه سلامة النقل، لكنها لا تثبت هوية الناشر بشكل مستقل.

## الترخيص والإشعارات

يسمح ترخيص Madabina CLI بالاستخدام وإعادة التوزيع المجاني للملفات التنفيذية الأصلية غير المعدّلة، وفقاً لشروط الترخيص المرفق. ولا يسمح بإعادة توزيع الشيفرة المصدرية أو الملفات التنفيذية المعدّلة. تتطلب إعادة البيع إذناً كتابياً منفصلاً من Madabina LLC. راجع [الترخيص](LICENSE) و[إشعارات المكونات الخارجية](THIRD_PARTY_NOTICES.md).

تخضع المكونات الخارجية لشروط تراخيصها الخاصة، وتوجد نسخها ضمن `third_party_licenses/` عند الاقتضاء.

## الأنظمة المستهدفة

تشمل الأنظمة المخطط دعمها Windows وLinux وmacOS بمعماريتي AMD64 وARM64، وحزم Debian لمعماريات Linux المدعومة، بالإضافة إلى حزمة منفصلة لنظام Android/Termux بمعمارية ARM64. لا يُعد أي نظام مدعوماً إلا إذا أُدرج في إصدار منشور.
