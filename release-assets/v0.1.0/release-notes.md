# Madabina CLI v0.1.0

This is the initial binary release of Madabina CLI by Madabina LLC. The repository contains distribution materials and release downloads; it does not publish the CLI source code.

## Downloads

Choose the archive for your operating system and CPU architecture:

- Windows: AMD64 or ARM64 ZIP archive
- Linux: AMD64 or ARM64 TAR.GZ archive
- macOS: AMD64 or ARM64 TAR.GZ archive
- Debian: AMD64 or ARM64 `.deb` package

Termux/Android is not included in this release.

## Validation notes

The Windows AMD64 binary was executed locally. Linux and macOS artifacts were cross-compiled; they were not executed on their target operating systems. The Linux installer script was not validated on an actual Linux runtime. Installers and packages should be reviewed for your environment before use.

The attached `checksums.txt` contains SHA-256 hashes for the release assets. A checksum downloaded from this same release helps detect transfer corruption or tampering in transit, but does not independently authenticate the publisher.
